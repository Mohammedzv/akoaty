# صفحة AKOYA للصحاب 💕
صفحة ويب رومانسية/لطيفة للصحاب البنات، فيها كلمة سر وأغنية وقلوب متحركة ورسالة شكر.

## كلمة السر
akoya

## إضافة الأغنية
ضع ملف الأغنية بصيغة MP3 داخل نفس مجلد المشروع، وسمّه:
song.mp3

شكل المجلد:
- index.html
- style.css
- script.js
- song.mp3

## تشغيل الصفحة
افتح index.html في المتصفح.

## رفعها على GitHub Pages
ارفع الملفات الأربعة (بما فيها song.mp3) إلى Repository، ثم فعّل GitHub Pages من Settings > Pages.

ملاحظة: كلمة السر الموجودة في JavaScript هي حماية شكلية للصفحة وليست حماية أمنية حقيقية، لأن ملفات المواقع الثابتة يمكن فحصها من المتصفح.
